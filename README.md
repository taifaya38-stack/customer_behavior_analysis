📊 Data Analytics Project
Overview

This project demonstrates an end-to-end data analytics workflow, from loading and cleaning raw data to extracting insights, performing SQL analysis, and presenting results through an interactive Power BI dashboard.

The project includes:

- Data loading using Python

- Exploratory Data Analysis (EDA)

- Data cleaning and preprocessing

- SQL analysis using PostgreSQL

- Power BI dashboard development

- Analytical report creation

- Presentation creation using Gamma

Dataset

The project uses a structured dataset containing business-related data for analysis.

The dataset was:

- Loaded and explored using Python

- Checked for missing values and duplicates

- Cleaned and transformed for analysis

- Loaded into PostgreSQL for SQL-based analysis

- Used to build the Power BI dashboard

Dataset: customer_shopping_behavior.csv

Tools & Technologies

- Python – Data loading, cleaning, and EDA

- Pandas – Data manipulation and preprocessing

- NumPy – Numerical analysis

- Matplotlib & Seaborn – Data visualization

- PostgreSQL – SQL queries and data analysis

- Power BI – Interactive dashboards and visualization

- PowerPoint – Presentation creation

- Jupyter Notebook – Python-based analysis

Steps
1. Data Loading

The dataset was imported into Python using Pandas. The initial analysis focused on understanding the dataset structure, columns, data types, and data quality.

2. Exploratory Data Analysis

EDA was performed to identify:

Data distributions

Missing values

Duplicate records

Outliers

Trends and patterns

Relationships between variables

Visualizations were created to better understand the data.

3. Data Cleaning

The dataset was prepared for analysis by:

Handling missing values

Removing duplicates

Correcting data types

Standardizing values

Handling inconsistencies

Treating outliers where necessary

4. SQL Analysis

The cleaned dataset was loaded into PostgreSQL.

SQL queries were used to perform:

Aggregations

Filtering and sorting

Grouping and segmentation

KPI calculations

Comparisons between categories

Trend analysis

5. Power BI Dashboard

The analyzed data was used to create an interactive Power BI dashboard.

The dashboard presents:

Key Performance Indicators (KPIs)

Interactive charts

Trends and comparisons

Category-level analysis

Filters and slicers

6. Report

A detailed analytical report was created to document the methodology, analysis, key findings, and conclusions from the project.

7. Presentation

A professional presentation was created using Gamma to summarize the project, methodology, key insights, and business recommendations.
